# A股报告生成与推送技能

定时生成A股晨报、晚报等多类报告，附带市场情绪评分与AI分析，推送至企业微信。

## 量化情绪打分规则（6维，满分100）

| 维度 | 满分 | 区间得分 |
|------|------|----------|
| ①涨停数量 | 15 | ≥150→15, ≥100→12, ≥60→9, ≥30→5, ≥10→2, <10→0 |
| ②涨跌停比 | 15 | ≥8→15, ≥5→12, ≥3→9, ≥1.5→5, ≥0.5→2, <0.5→0；跌停=0时直接15分 |
| ③北向资金 | 20 | ≥100亿→20, ≥50→15, ≥20→10, ≥0→6; 流出≥-50→3, <-50→0 |
| ④主力资金（全市场） | 20 | ≥500亿→20, ≥200→16, ≥50→12, ≥0→8; -200→5, -500→2, <-500→0 |
| ⑤炸板率（炸板数/涨停数） | 15 | <15%→15（强封板）, <25%→12, <35%→8, <45%→5, ≥45%→3；无数据→⚠️暂缺 |
| ⑥沪深300 | 10 | ≥+2%→10, ≥+1%→8, ≥0%→6; -1%→4, <-1%→0 |

**综合评级**：≥85→🟢极强多头 | ≥68→🟡多头偏强 | ≥52→⚪中性震荡 | ≥36→🟠偏空谨慎 | <36→🔴极弱空头

**⚠️ 评分保护**：任意一项数据暂缺 → 整体等级显示"⚠️数据暂缺，无法评分"（不是0分，不计入）。

**市场风险偏好**（晚报专用）： `两融比例 = 融资买入额 / 全市场成交额 × 100%` <7% → 保守 | 7~11% → 中性 | >11% → 过热

**两融余额占比预警**（晚报专用）： `两融余额占比 = 两融余额 / A股流通市值 × 100%`
> 3.2% → ⚠️ 预警区（战略撤退） | >3.5% → 高危区（必须撤离）

⚠️ **数据日期一致性原则（关键）**：
• 两融余额、两融交易额：均为 T-1 日盘后更新，属昨日数据
• 全市场成交额、流通市值：T 日实时数据
• 比例行下方须注明分子和分母各自的日期

## 数据源

| 数据项 | 正确来源 | 单位换算 |
|--------|----------|----------|
| 六大指数 | 腾讯 `qt.gtimg.cn` field[32]涨跌幅 | URL格式 `qt.gtimg.cn/q=sh000001,sz399001...` |
| 涨停家数 | akshare `stock_zt_pool_em(date=今天)` | — |
| 北向资金 | akshare `stock_hsgt_fund_flow_summary_em` | 列名 `成交净买额`（万元→÷10000=亿） |
| 两融余额 | akshare `stock_margin_account_info` | **融资余额 + 融券余额**（已是亿元） |
| 全市场成交额 | 沪市 `stock_sse_deal_daily` + 深市 `stock_szse_summary` + 北交所 `stock_bse_summary` | 沪市亿元；深市/北交所元÷1e8 |
| 沪深300PE | 腾讯 `sh000300` field[39] | 直接是数字（倍） |
| 10年国债收益率 | akshare `bond_china_yield` | 返回%（如1.81） |

⚠️ **核心原则**：今日数据暂缺时，返回 `None`，由 AI 搜索补全；**禁止取昨日数据凑数**。

## 推送方式

支持企业微信机器人 Webhook 推送。
Webhook Key 优先读环境变量 `WECOM_WEBHOOK_KEY`，回退 `keys/` 目录 ini 文件。
